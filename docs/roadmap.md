# Roadmap

## 0.1 — Local observatory

- Import JSON/CSV.
- Dashboard metrik dan evidence.
- Safe aggregate export.
- User-initiated Chromium capture.

## 0.2 — Better imports

- Importer untuk arsip data resmi.
- Preview dan redaksi sebelum penyimpanan.
- Deduplication berbasis content hash.
- IndexedDB untuk snapshot besar.

## 0.3 — On-device intelligence

- Embedding multibahasa via WebGPU.
- Topic clustering tanpa kategori tetap.
- Explainable similarity dan confidence.
- Seluruh model bersifat opsional serta dapat dihapus.

## 0.4 — Personal experiments

- Bandingkan chronological feed dan recommended feed.
- Catat perubahan setelah mute/follow tanpa mengontrol akun.
- Reminder eksperimen yang tidak menggunakan streak atau guilt.

## 1.0 — Research commons

- Schema dataset terbuka.
- Differentially private cohort summaries.
- Governance kamus komunitas.
- Reproducible benchmark Bahasa Indonesia.
